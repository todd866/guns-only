Coordinates use a local metre frame (+x east, +z south), origin 36.241303 N, 115.04465775 W. Building heights and gameplay clearings are authored approximations, not source measurements. The game perimeter is an authored bounded window, not the real base fence.

`residential.json` is a separate adapted OSM extract in a rotated, translated game
coordinate frame. Street lengths and building footprints retain metre scale;
heights, materials, vegetation shapes and gameplay details are approximations.
It is distributed as part of this ODbL derived database. Its generic game names
do not identify the source neighbourhood.
