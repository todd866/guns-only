# Top Gun (1986) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a sibling front-door experience **Top Gun** — playable F-14A vs MiG-28 (F-5E-class under fiction name), M61 + AIM-9, anime-1986 presentation — starting as `coming-soon`, then `preview` when a dogfight flies.

**Architecture:** Fixed-wing ACM on the existing `AircraftSim` / Fight Director stack (not a motorcycle-style parallel vehicle). New sourced airframe params + beat `Beats.TopGunAcm`. AIM-9 lives in a dedicated `sim/Missiles/` lane (honest PN/seeker toy), called from a thin Top Gun–gated path — do **not** bolt heaters onto `first-merge`. Experience-scoped presentation theme (`top-gun-anime-1986`) skins Ready/HUD without rewriting the global renderer. Prefer new files over editing contended `SimulationSession.cs`; when a session hook is unavoidable, keep it beat-gated and minimal.

**Tech Stack:** C# (.NET 8) `GunsOnly.Sim`, xUnit, existing Blazor WASM + `web/wwwroot` render stack. Spec: `docs/superpowers/specs/2026-08-03-top-gun-design.md`.

**Test invocation:**
`$HOME/.dotnet/dotnet test sim.Tests/GunsOnly.Sim.Tests.csproj --filter "FullyQualifiedName~TopGun"`
Catalog/release: `node --test web/wwwroot/render/release/tests/quarantine_gate.test.mjs` (and progression tests if present).

## Global Constraints

- **Sibling product:** Sidewinders are Top Gun only. Never enable AIM-9 on `first-merge` / F-22 guns-only.
- **Naming:** Catalog title **Top Gun**; aggressor identity **MiG-28** in UI. Never advertise “F-14 vs F-5” on the front door. MiG-28 folder states fiction overlay + F-5 provenance.
- **Epistemics:** every numeric claim `measured` / `surrogate` / `provisional` / `fiction` with sources files. No silent invented precision.
- **v1 loadout (resolved):** **2× AIM-9** per seat (provisional); gun as existing ballistics pattern (M61 for Tomcat; F-5E-class gun for MiG-28). No AIM-54 / AIM-7.
- **RIO (resolved):** absent in v1 — single-seat control fantasy (no player RIO).
- **Swing-wing (resolved):** scheduled sweep vs Mach/CAS table; publish `wing_sweep_deg` on snapshot; coarse aero effect required before preview.
- **Missiles (resolved):** new `sim/Missiles/Aim9Surrogate.cs` — do not reuse Rapier’s timed-impact helper as-is; may share PN math ideas only.
- **Release ladder:** catalog lands as **`coming-soon`** (Task 3); promote to **`preview`** only after Task 10 automation + a human dogfight note in STATUS.
- **IP:** original vibe product — no Paramount marks, dialogue, or licensed soundtrack in v1.
- **Never `git add -A`.** Stage explicit paths. Plan “Commit” steps are checkpoints; follow user commit rules in-session.
- **Claims:** `bin/claim take` before editing held files; prefer new files over `SimulationSession.cs` / `Beats.cs` collisions.
- **Theatre:** Miramar-energy training range fiction (coast/desert light) — not carrier trap as a v1 gate.
